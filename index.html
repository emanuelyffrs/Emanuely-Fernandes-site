Featured project

AI-Powered Translator

Python, LangChain & Gemini

A translation tool where the target language and the text are inputs rather than fixed in the code. Instead of a script that only translates one sentence into one language, a single chain can translate any text into whichever language is requested.

How it works

  • A chat prompt template holds a system instruction and a user message, with the language and the text as variables.
  • The prompt is connected to Google’s Gemini model through the LangChain integration and then to a string output parser, forming one chain.
  • The chain is exposed as an API with FastAPI and LangServe, and the Gemini API key is read from an environment variable instead of being written in the code.

What I practiced

Building chains in LangChain, writing prompt templates with variables, calling a language model from Python, handling credentials with environment variables, and serving a model-backed endpoint.
